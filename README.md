# CozyFall

The Mushroom Game is a cozy fall survival game where you control a mushroom, dodge falling rocks, and try to survive for 60 seconds.

<img width="1394" height="683" alt="Screenshot 2026-09-26 at 8 56 34 PM" src="https://github.com/user-attachments/assets/a8330409-10c1-4d1f-a8fb-0ec0e9d75300" />

Link to Repo: https://github.com/rushil0077/CozyFall

Link to Game: https://rushil0077.github.io/CozyFall/

- Control a mushroom using WASD.
- Dodge falling rocks that randomly spawn.
- Survive for 60 seconds without getting hit to win.
- Hard Mode makes rocks fall more faster.
- Play Again after winning or losing.
